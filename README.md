# Dice Rolling Simulator

## Description

This is a simple Dice Rolling Simulator created using Python. The program simulates rolling a six-sided die and displays a random number between **1** and **6**. The user can continue rolling the dice as many times as they want.

## Features

* Beginner-friendly Python code
* Generates a random dice roll
* Allows multiple rolls
* Easy to understand and modify

## Requirements

* Python 3.x

## How to Run

1. Save the Python code in a file named `dice_rolling_simulator.py`.
2. Open a terminal or command prompt.
3. Navigate to the folder containing the file.
4. Run the following command:

```bash
python dice_rolling_simulator.py
```

## Example

```text
Press Enter to roll the dice...

You rolled: 4

Roll again? (yes/no): yes

Press Enter to roll the dice...

You rolled: 1

Roll again? (yes/no): no

Thanks for playing!
```
